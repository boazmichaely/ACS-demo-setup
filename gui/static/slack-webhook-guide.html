Maintainer note: Slack Incoming Webhook

Demo labs typically use channel #acs-demo-notifier. The Incoming Webhook URL is stored only in Lab credentials (never in the shared defaults file). Day-to-day users follow this page when the webhook field is empty.

When to use this guide Create or rotate an Incoming Webhook, then paste the URL into Lab credentials → Integration Secrets → Slack notifier.

  1. Open the Slack "Your Apps" page

    In a normal browser, go to https://api.slack.com/apps. You should already see Workspace Internal Red Hat.

  2. Open the app, then Incoming Webhooks

    Click ACS Demo Slack Notifier. You land on Basic Information. Client Secret / Signing Secret here are unrelated to the Incoming Webhook URL ACS needs - leave them alone.

    In the left sidebar under Features, click Incoming Webhooks (red box).

  3. Confirm the shared channel row

    On the Incoming Webhooks page:

    • Toggle should be On.
    • Under Webhook URLs for Your Workspace, find the row whose Channel is #acs-demo-notifier.
    • If the channel was renamed in Slack, the Channel column updates here (no need to recreate the webhook).
    • If that row is missing: click Add New Webhook, pick #acs-demo-notifier, authorize, then use the new row.

  4. Copy the webhook and smoke-test

    Click Copy on the #acs-demo-notifier row. Do not paste the URL into chat, tickets, or git.

    Local smoke test:

    curl -sS -X POST -H 'Content-type: application/json' \
  --data '{"text":"ACS demo setup: webhook spike test"}' \
  'PASTE_WEBHOOK_URL_HERE'

    Success is a plain ok response and a message in #acs-demo-notifier.

    Spike verified: test message landed in #acs-demo-notifier.

  5. Update Lab credentials

    In ACS demo setup GUI, under Integration Secrets follow these two steps.

    1. Paste the webhook URL that you got from step four above.
    2. Paste the Slack channel URL by copying the Slack channel URL from Slack itself.

    Then click Save.

    If you want to reset the notifier name and channel URL to the default values, click Restore defaults.

Module slack-notifier creates the Central Slack integration and sends a test message on --run.
